# SciQA Dataset Structure

This document describes the structure and format of the SciQA dataset (based on the Open Research Knowledge Graph) used in the AMA-KBQA system.

## Overview

SciQA is a scientific question-answering benchmark built on the Open Research Knowledge Graph (ORKG). It contains:

- **~1.1M RDF triples** from the ORKG dump
- **468 question-answer pairs** (100 handcrafted + 368 auto-generated)
- Academic domain focus (papers, authors, contributions, research fields)

## File Locations

```
db/datasets/SciQA/
├── ORKG RDF dump 14.02.2023.nt     # RDF N-Triples (~160 MB, 1.1M triples)
├── Handcrafted/                     # Expert-written Q&A pairs
│   ├── train.csv                    # Training set
│   └── test.csv                     # Test set
├── Autogenerated/                   # Machine-generated Q&A pairs
│   ├── train.csv                    # Training set (~44K lines)
│   └── test.csv                     # Test set (~11K lines)
└── HF/                              # HuggingFace dataset format
    └── *.arrow                      # Apache Arrow format
```

## Knowledge Graph Structure

### Graph URI

The ORKG data is loaded into Virtuoso with the graph URI:
```
http://orkg.org/kg
```

### Namespace Prefixes

```sparql
PREFIX orkgr: <http://orkg.org/orkg/resource/>
PREFIX orkgc: <http://orkg.org/orkg/class/>
PREFIX orkgp: <http://orkg.org/orkg/predicate/>
PREFIX rdfs:  <http://www.w3.org/2000/01/rdf-schema#>
PREFIX rdf:   <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX xsd:   <http://www.w3.org/2001/XMLSchema#>
```

### Key Classes

| Class URI | Label | Description |
|-----------|-------|-------------|
| `orkgc:Paper` | Paper | Research papers |
| `orkgc:Author` | Author | Paper authors |
| `orkgc:Contribution` | Contribution | Research contributions |
| `orkgc:ResearchField` | Research Field | Scientific domains |
| `orkgc:Venue` | Venue | Conferences/journals |
| `orkgc:Problem` | Problem | Research problems addressed |
| `orkgc:FeaturedComparison` | Featured Comparison | Comparison between papers |
| `orkgc:Resource` | Resource | Generic resources |

### Key Predicates

| Predicate URI | Label | Description |
|---------------|-------|-------------|
| `orkgp:P0` | addresses | Problem addressed by contribution |
| `orkgp:P1` | yields | Result yielded by contribution |
| `orkgp:P2` | employs | Method employed |
| `orkgp:P6` | author | Paper author |
| `orkgp:P7` | affiliation | Author affiliation |
| `orkgp:P10` | DOI | Digital Object Identifier |
| `orkgp:P26` | has DOI | Alternative DOI predicate |
| `orkgp:P27` | has venue | Publication venue |
| `orkgp:P28` | publication year | Year of publication |
| `orkgp:P29` | month | Publication month |
| `orkgp:P30` | has research field | Research field |
| `orkgp:P31` | has contribution | Paper contributions |
| `orkgp:P32` | research problem | Research problem |

## Question-Answer Dataset Structure

### CSV Format

Both handcrafted and autogenerated datasets use CSV format with these columns:

| Column | Description |
|--------|-------------|
| `id` | Unique question identifier |
| `question` | Natural language question |
| `query` | Executable SPARQL query |
| `answer` | Ground truth answer |
| `Q type` | Question type classification |
| `Q shape` | Query structure (Tree, DAG, Cyclic) |
| `Query components` | Count of SPARQL elements |
| `No. of triple patterns` | Number of graph patterns |
| `Q Keywords/Operators` | SPARQL operators used |

### Example Entry

```csv
id,question,query,answer,Q type,Q shape,Query components,No. of triple patterns,Q Keywords/Operators
sciqa_001,"What papers address the problem of text classification?","SELECT ?paper WHERE { ?paper orkgp:P31 ?contrib . ?contrib orkgp:P0 ?problem . ?problem rdfs:label \"text classification\" }","R12345, R67890",Factoid,Tree,3,2,"SELECT, WHERE"
```

### Question Types

| Type | Description |
|------|-------------|
| Factoid | Simple fact-based questions |
| Non-factoid | Complex reasoning questions |
| Count | Counting questions ("How many...") |
| Boolean | Yes/No questions |
| List | Questions expecting multiple answers |

### Query Shapes

| Shape | Description |
|-------|-------------|
| Tree | Simple tree-structured queries |
| DAG | Directed Acyclic Graph patterns |
| Cyclic | Queries with cyclic patterns |

### SPARQL Operators Used

Common operators found in SciQA queries:
- `SELECT`, `DISTINCT`, `WHERE`
- `FILTER`, `REGEX`, `CONTAINS`
- `ORDER BY`, `LIMIT`, `OFFSET`
- `GROUP BY`, `HAVING`, `COUNT`
- `OPTIONAL`, `UNION`

## SPARQL Query Examples

### Find Papers by Research Field

```sparql
PREFIX orkgr: <http://orkg.org/orkg/resource/>
PREFIX orkgp: <http://orkg.org/orkg/predicate/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT ?paper ?title WHERE {
  GRAPH <http://orkg.org/kg> {
    ?paper orkgp:P30 ?field .
    ?field rdfs:label "Natural Language Processing" .
    ?paper rdfs:label ?title .
  }
}
```

### Find Papers by Author

```sparql
SELECT ?paper ?title WHERE {
  GRAPH <http://orkg.org/kg> {
    ?paper orkgp:P6 ?author .
    ?author rdfs:label "Jane Smith" .
    ?paper rdfs:label ?title .
  }
}
```

### Find Contributions for a Problem

```sparql
SELECT ?contrib ?label WHERE {
  GRAPH <http://orkg.org/kg> {
    ?contrib orkgp:P0 ?problem .
    ?problem rdfs:label "text classification" .
    ?contrib rdfs:label ?label .
  }
}
```

## Comparison with KQAPro

| Feature | KQAPro | SciQA |
|---------|--------|-------|
| Domain | General knowledge | Academic/Scientific |
| Triples | ~1.6M | ~1.1M |
| Entities | ~47K | ~100K+ |
| Q&A Pairs | ~94K | ~468 |
| Qualifiers | Rich support | Limited |
| Typed Values | Yes (quantity, date) | Basic |
| Expert Curation | Some | 100 handcrafted |
